# CPP-OOP-Practical-10

## Aim
To implement class templates and function templates in C++ using a real-life example.

## Real-Life Example
**Student Result Management System**

This practical demonstrates the use of class templates and function templates to calculate and display students' marks.

## Concepts Used
- Function Template
- Class Template
- Generic Programming
- Constructors and Objects
- Code Reusability

## Description

### 1. Function Template
A function template is used to calculate the total marks of a student. It allows the same function to work with different data types without writing separate functions.

### 2. Class Template
A class template is used to store and display student details, including roll number, marks in three subjects, and total marks. It supports different numeric data types, such as `int` and `float`.

## Advantages of Templates
- Reduces code duplication.
- Supports different data types.
- Improves code reusability.
- Makes programs easier to maintain.

## Conclusion
Thus, class templates and function templates were implemented successfully using a real-life Student Result Management System in C++.
